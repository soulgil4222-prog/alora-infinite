# Alora Infinite - Starter Repo (NEXT_STUB)
This is a starter skeleton for Alora Infinite (Next.js + Tailwind + Supabase + Stripe).
Files included:
- pages/index.js : Landing + assessment form (React)
- pages/results.js : Results page
- pages/api/assessments.js : API route to persist assessment + call OpenAI
- pages/api/create-checkout.js : Stripe Checkout session creator
- supabase/schema.sql : Basic DB schema
- .env.example : Environment variables to set
- Dockerfile : Example Dockerfile
- .github/workflows/ci.yml : Basic CI workflow for Vercel/GitHub Actions
